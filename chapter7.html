第7章 演算法與數值方法

雖然量化從業者花在程式設計上的時間百分比因工作職能（如量化分析師/研究員vs量化開發者）和公司文化而異，但典型的量化從業者通常會將部分時間用於通過程式設計實現模型。因此，程式設計技能測試通常是量化面試不可分割的一部分。

在很大程度上，量化面試中的程式設計問題與技術面試中的類似。毫不意外，許多問題是平臺或語言特定的。雖然C++和Java仍然主導市場，但我們看到越來越多的語言多樣化，如Matlab、SAS、S-Plus和R。由於已有許多書籍和網站專門討論技術面試，本章不會全面回顧程式設計問題。相反，它討論一些在量化面試中最受歡迎的演算法問題和數值方法。

7.1 演算法

在程式設計中，演算法複雜度分析通常使用漸近分析（Asymptotic Analysis），忽略機器相關的常數，研究執行時間 \(T(n)\)——原始操作（如加法、乘法和比較）的數量——隨輸入數量 \(n \to \infty\) 的變化。

演算法複雜度中三個最重要的記號是大O記號、\(\Omega\) 記號和 \(\Theta\) 記號：

  • \(O(g(n)) = \{f(n)\)：存在正常數 \(c\) 和 \(n_0\)，使得對所有 \(n \geq n_0\)，\(0 \leq f(n) \leq cg(n)\}\)。它是 \(f(n)\) 的漸近上界。
  • \(\Omega(g(n)) = \{f(n)\)：存在正常數 \(c\) 和 \(n_0\)，使得對所有 \(n \geq n_0\)，\(0 \leq cg(n) \leq f(n)\}\)。它是 \(f(n)\) 的漸近下界。
  • \(\Theta(g(n)) = \{f(n)\)：存在正常數 \(c_1\)、\(c_2\) 和 \(n_0\)，使得對所有 \(n \geq n_0\)，\(c_1g(n) \leq f(n) \leq c_2g(n)\}\)。它是 \(f(n)\) 的漸近緊界。

除了記號之外，解釋演算法複雜度中的兩個概念也很重要：

最壞情況執行時間 \(W(n)\)：對任意 \(n\) 個輸入的執行時間上界。

平均情況執行時間 \(A(n)\)：如果 \(n\) 個輸入是隨機選擇的，期望執行時間。

對於許多演算法，\(W(n)\) 和 \(A(n)\) 具有相同的 \(O(g(n))\)。但正如我們將要討論的，在某些問題中它們可能不同，其相對重要性往往取決於具體問題。

一個有 \(n\) 個輸入的問題通常可以被分割成 \(a\) 個子問題，每個子問題有 \(n/b\) 個輸入。這種範式通常稱為分治法（Divide-and-Conquer）。如果將問題分割成子問題併合並解所需的原始操作為 \(f(n)\)，執行時間可以表示為遞推方程 \(T(n) = aT(n/b) + f(n)\)，其中 \(a \geq 1\)，\(b > 1\)，且 \(f(n) \geq 0\)。

主定理（Master Theorem）是求解遞推方程 \(T(n) = aT(n/b) + f(n)\) 緊界的有力工具：

  • 如果 \(f(n) = O(n^{\log_b a - \varepsilon})\)，對某個常數 \(\varepsilon > 0\)，則 \(T(n) = \Theta(n^{\log_b a})\)。
  • 如果 \(f(n) = \Theta(n^{\log_b a}\log^k n)\)，對某個 \(k \geq 0\)，則 \(T(n) = \Theta(n^{\log_b a}\log^{k+1} n)\)。
  • 如果 \(f(n) = \Omega(n^{\log_b a + \varepsilon})\)，對某個常數 \(\varepsilon > 0\)，且 \(af(n/b) \leq cf(n)\)，對某個常數 \(c < 1\)，則 \(T(n) = \Theta(f(n))\)。

二分查詢示例：要在有序陣列中查詢一個元素，演算法從 \(a_{\lfloor n/2 \rfloor}\) 開始，每次將搜尋元素數量減半，只需進行一次比較。所以 \(a = 1\)，\(b = 2\)，\(f(n) = 1\)。因此二分查詢的複雜度為 \(\Theta(\log n)\)。

數字交換

如何在不使用額外儲存空間的情況下交換兩個整數 \(i\) 和 \(j\)？

💡 點選檢視解答

比較和交換是許多演算法的基本操作。最常見的交換技術使用臨時變數，但在這個問題中不允許使用。一個簡單的數學方法是先儲存 \(i\) 和 \(j\) 的和，然後提取各自的值：

void swap(int &i, int &j) {
    i = i + j;    //儲存i和j的和
    j = i - j;    //將j變為i的值
    i = i - j;    //將i變為j的值
}

另一種方案使用按位異或（XOR）運算，利用 \(x \oplus x = 0\) 和 \(0 \oplus x = x\) 的事實：

void swap(int &i, int &j){
    i = i ^ j;
    j = j ^ i;   //j = i ^ (j ^ i) = i
    i = i ^ j;   //i = (i ^ j) ^ i = j
}

唯一元素

如果給你一個已排序的陣列，你能寫一些程式碼來提取陣列中的唯一元素嗎？例如，如果陣列是[1, 1, 3, 3, 3, 5, 5, 5, 9, 9, 9, 9]，唯一元素應該是[1, 3, 5, 9]。

💡 點選檢視解答

設 \(a\) 為一個有 \(n\) 個元素的已排序陣列。每當我們遇到一個新元素 \(a_i\) 時，它的值與前一個元素不同（\(a_i \neq a_{i-1}\)）。利用這個性質我們可以輕鬆提取唯一元素：

template <class T> vector<T> unique(T a[], int n) {
    vector<T> vec; // 使用vector避免大小調整問題
    vec.reserve(n); //預留空間避免重新分配
    vec.push_back(a[0]);
    for(int i=1; i<n; ++i) {
        if(a[i] != a[i-1])
            vec.push_back(a[i]);
    }
    return vec;
}

霍納演算法

編寫一個演算法計算 \(y = A_0 + A_1x + A_2x^2 + A_3x^3 + \cdots + A_nx^n\)。

💡 點選檢視解答

樸素方法分別計算多項式的每個分量然後相加，需要 \(O(n^2)\) 次乘法。我們可以使用霍納演算法（Horner's Algorithm）將乘法次數減少到 \(O(n)\)。

該演算法將原始多項式表示為：

\[y = (((A_nx + A_{n-1})x + A_{n-2})x + \cdots + A_1)x + A_0\]

然後依次計算：\(B_n = A_n\)，\(B_{n-1} = B_nx + A_{n-1}\)，...，\(B_0 = B_1x + A_0\)。我們有 \(y = B_0\)，最多需要 \(n\) 次乘法。

移動平均

給定一個長度為 \(m\) 的大陣列 \(A\)，你能開發一個高效演算法來構建另一個包含原始陣列 \(n\) 元素移動平均的陣列嗎？

（\(B_1, \cdots, B_{n-1} = NA\)，\(B_i = (A_{i-n+1} + A_{i-n+2} + \cdots + A_i)/n\)，\(\forall i = n, \cdots, m\)）

💡 點選檢視解答

當我們計算下一個 \(n\) 個連續數字的移動平均時，可以重用之前計算的移動平均。只需將該平均值乘以 \(n\)，減去該移動平均中的第一個數字，然後加上新數字，就得到新的和。

S = A[1] + ... + A[n]; B[n] = S/n;
for (i = n+1 to m) {
    S = S - A[i-n] + A[i];
    B[i] = S/n;
}

排序演算法

你能解釋三種排序演算法來對 \(n\) 個不同的值 \(A_1, \cdots, A_n\) 進行排序，並分析每種演算法的複雜度嗎？

💡 點選檢視解答

插入排序（Insertion Sort）

插入排序使用增量方法。假設我們已經排好了子陣列A[1, ..., i-1]。我們將元素 \(A_i\) 插入A[1, ..., i-1]中的適當位置，得到已排序子陣列A[1, ..., i]。

每步的期望比較次數為 \(i/2\)，最壞情況比較次數為 \(i\)。所以：

\[A(n) = \Theta\left(\sum_{i=1}^{n}i/2\right) = \Theta(n^2), \quad W(n) = \Theta\left(\sum_{i=1}^{n}i\right) = \Theta(n^2)\]

歸併排序（Merge Sort）

歸併排序使用分治範式。它將陣列分成兩個子陣列，每個有 \(n/2\) 個元素，遞迴排序後合併。

mergesort(A, beginindex, endindex)
    if beginindex < endindex
        then centerindex ← (beginindex + endindex)/2
            merge1 ← mergesort(A, beginindex, centerindex)
            merge2 ← mergesort(A, centerindex + 1, endindex)
            merge(merge1, merge2)

執行時間遞推函式：

\[T(n) = \begin{cases} 2T(n/2) + \Theta(n), & \text{if } n > 1 \\ 1, & \text{if } n = 1 \end{cases}\]

應用主定理，\(a = 2\)，\(b = 2\)，\(f(n) = \Theta(n)\)，所以 \(T(n) = \Theta(n\log n)\)。

快速排序（Quicksort）

快速排序從序列中選擇一個元素 \(A_i\)，將所有其他值與之比較。小於 \(A_i\) 的放入左邊子陣列，大於的放入右邊子陣列，然後遞迴。

最壞情況：當陣列已排序且總選擇第一個元素時，\(W(n) = \Theta(n^2)\)。

平均情況：設 \(\tilde{A}_p\) 和 \(\tilde{A}_q\) 被比較的機率為 \(P(p,q) = \frac{2}{q-p+1}\)，則：

\[A(n) = \sum_{q=2}^{n}\sum_{p=1}^{q-1}\frac{2}{q-p+1} = \Theta(n\log n)\]

雖然理論上快速排序在最壞情況下可能比歸併排序慢，但它在實際中往往和歸併排序一樣快，甚至更快。

隨機排列

A. 如果你有一個隨機數生成器，你如何洗一副52張牌使得每種排列都等可能？

💡 點選檢視解答

方法一：排序隨機排列。為每張牌分配一個隨機數，然後按照分配的隨機數順序排列牌。複雜度為 \(\Theta(n\log n)\)。

方法二：Knuth洗牌（複雜度 \(\Theta(n)\)）：

for (i = 1 to n)
    swap(A[i], A[Random(i, n)])

其中Random(i, n)是來自 \(i\) 和 \(n\) 之間離散均勻分佈的隨機數。

直覺：在第一步中，\(n\) 張牌中的每張都有相同機率被選為第一張牌；在第二步中，剩餘 \(n-1\) 張牌中的每張都有相同機率被選為第二張牌；依此類推。每個有序序列都有 \(1/n!\) 的機率。

B. 你有一個由字元組成的檔案。檔案中的字元可以順序讀取，但檔案長度未知。你如何選取一個字元使得檔案中每個字元被選中的機率相等？

💡 點選檢視解答

從選第一個字元開始。如果有第二個字元，以機率1/2保留第一個字元，以機率1/2用第二個字元替換。如果有第三個字元，以機率2/3保留選擇，以機率1/3替換。

一般地，設 \(C_n\) 為掃描 \(n\) 個字元後的選擇，當第 \((n+1)\) 個字元存在時：

  • 保留選擇的機率為 \(\frac{n}{n+1}\)
  • 切換到第 \((n+1)\) 個字元的機率為 \(\frac{1}{n+1}\)

使用歸納法可證明：如果有 \(m\) 個字元，每個字元被選中的機率為 \(1/m\)。

搜尋演算法

A. 設計一個演算法，使用不超過 \(3n/2\) 次比較來找到 \(n\) 個數的最小值和最大值。

💡 點選檢視解答

將元素分成 \(n/2\) 對，比較每對中的元素，將較小的放入組 \(A\)，較大的放入組 \(B\)（需 \(n/2\) 次比較）。

由於最小值必在組 \(A\) 中，最大值必在組 \(B\) 中，只需找到 \(A\) 中的最小值和 \(B\) 中的最大值，每個需要 \(n/2-1\) 次比較。總比較次數最多為 \(3n/2\)。

B. 給你一個數字陣列。從陣列開始到某個位置，所有元素都是零；之後所有元素都是非零的。如果你不知道陣列大小，如何找到第一個非零元素的位置？

💡 點選檢視解答

從第1個元素開始；如果是零，檢查第2個元素；如果仍是零，檢查第4個元素...重複直到第 \(2^i\) 個元素是非零的。然後在 \(2^{i-1}\) 和 \(2^i\) 之間進行二分查詢。

如果第一個非零元素在位置 \(n\)，演算法複雜度為 \(\Theta(\log n)\)。

C. 你有一個方形數字網格。每行從左到右遞增，每列從上到下遞增。設計算法在網格中查詢一個給定數字。

💡 點選檢視解答

設 \(A\) 為 \(n \times n\) 矩陣，\(x\) 為要查詢的數字。從最後一列的頂部開始從上到下搜尋。

  • 如果 \(A_{i,n} < x < A_{i+1,n}\)，排除前 \(i\) 行，沿第 \((i+1)\) 行從右向左搜尋
  • 如果 \(A_{i+1,j+1} > x > A_{i+1,j}\)，排除第 \(j+1, \cdots, n\) 列，沿第 \(j\) 列向下搜尋
  • 如此交替行列搜尋，直到找到 \(x\) 或確定其不存在

使用這個演算法，搜尋最多需要 \(2n\) 步，複雜度為 \(O(n)\)。

斐波那契數

考慮以下計算斐波那契數的C++程式。如果對某個大的 \(n\)，計算Fibonacci(n)需要100秒，那麼計算Fibonacci(n+1)需要多長時間？這個演算法高效嗎？你會如何計算斐波那契數？

int Fibonacci(int n)
{
    if (n <= 0)
        return 0;
    else if (n == 1)
        return 1;
    else
        return Fibonacci(n-1) + Fibonacci(n-2);
}
💡 點選檢視解答

斐波那契數定義為：\(F_0 = 0\)，\(F_1 = 1\)，\(F_n = F_{n-1} + F_{n-2}\)，\(\forall n \geq 2\)。

封閉形式解：

\[F_n = \frac{(1+\sqrt{5})^n - (1-\sqrt{5})^n}{2^n\sqrt{5}}\]

從程式可知 \(T(0) = 1\)，\(T(1) = 1\)，\(T(n) = T(n-1) + T(n-2) + 1\)。執行時間正比於斐波那契數序列。

對於大的 \(n\)：\(\frac{T(n+1)}{T(n)} \approx \frac{\sqrt{5}+1}{2}\)。所以計算Fibonacci(n+1)的時間約為 \(\frac{\sqrt{5}+1}{2} \times 100 \approx 162\) 秒。

遞迴演算法具有指數複雜度 \(\Theta\left(\left(\frac{\sqrt{5}+1}{2}\right)^n\right)\)，非常低效。

更高效的方法

迭代法 \(\Theta(n)\)：按順序計算 \(F_0, F_1, \cdots, F_n\)。

遞迴平方法 \(\Theta(\log n)\)：利用矩陣關係：

\[\begin{bmatrix} F_{n+1} & F_n \\ F_n & F_{n-1} \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}^n\]

設 \(A = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}\)，使用分治計算 \(A^n\)：

\[A^n = \begin{cases} A^{n/2} \times A^{n/2}, & \text{if } n \text{ is even} \\ A^{(n-1)/2} \times A^{(n-1)/2} \times A, & \text{if } n \text{ is odd} \end{cases}\]

兩個 \(2 \times 2\) 矩陣的乘法複雜度為 \(\Theta(1)\)，所以 \(T(n) = T(n/2) + \Theta(1)\)，應用主定理得 \(T(n) = \Theta(\log n)\)。

最大連續子陣列

假設你有一個長度為 \(n\) 的一維陣列 \(A\)，包含正數和負數。設計一個演算法找到任意連續子陣列 \(A[i, j]\) 的最大和：\(V(i, j) = \sum_{x=i}^{j}A[x]\)，\(1 \leq i \leq j \leq n\)。

💡 點選檢視解答

幾乎所有交易系統都需要這樣一個演算法來計算最大上漲（Maximum Run-up）或最大回撤（Maximum Drawdown）。

\(O(n^2)\) 演算法

從頭開始依次計算 \(V(i, j)\)：\(V(i, i) = A[i]\)，\(V(i, j) = V(i, j-1) + A[j]\)（當 \(j > i\)）。

\(O(n)\) 演算法

定義 \(T(i) = \sum_{x=1}^{i}A[x]\) 且 \(T(0) = 0\)，則 \(V(i, j) = T(j) - T(i-1)\)。對於固定的 \(j\)，當 \(T(i-1)\) 最小化時，\(V(i, j)\) 最大化。

T = A[1]; V_max = A[1]; T_min = min(0, T)

For j = 2 to n
{   T = T + A[j];
    If T - T_min > V_max then V_max = T - T_min;
    If T < T_min, then T_min = T;
}
Return V_max;

C++實現：

double maxSubarray(double A[], int len, int &i, int &j)
{
    double T=A[0], Vmax=A[0];
    double Tmin = min(0.0, T);
    for(int k=1; k<len; ++k)
    {
        T += A[k];
        if (T-Tmin > Vmax) {Vmax=T-Tmin; j=k;}
        if (T<Tmin) {Tmin = T; i = (k+1<j)? (k+1):j;}
    }
    return Vmax;
}

示例：

double A[]={1.0, 2.0, -5.0, 4.0, -3.0, 2.0, 6.0, -5.0, -1.0};
int i = 0, j = 0;
double Vmax = maxSubarray(A, sizeof(A)/sizeof(A[0]), i, j);

結果：\(V_{max} = 9\)，\(i = 3\)，\(j = 6\)。子陣列為 [4.0, -3.0, 2.0, 6.0]。

7.2 二的冪

世界上只有10種人——懂二進位制的和不懂的。計算機使用二進位制（base-2）數字系統執行。與十進位制數字0-9不同，每個位（bit）只有兩個可能的值：0和1。數字的二進位制表示具有一些有趣的性質，在實踐中被廣泛探索。

2的冪判斷

如何判斷一個整數是否是2的冪？

💡 點選檢視解答

任何整數 \(x = 2^n\)（\(n \geq 0\)）只有一個位被設為1。例如，\(8 (= 2^3)\) 表示為 0...01000。

同樣，\(2^n - 1\) 的右邊 \(n\) 位全部設為1。例如，7表示為 0...00111。

所以 \(2^n\) 和 \(2^n - 1\) 沒有共同的位。因此：

// 判斷x是否為2的冪
bool isPowerOfTwo(int x) {
    return (x > 0) && ((x & (x - 1)) == 0);
}

\(x \& (x-1) = 0\) 即為判斷條件（其中 & 是按位AND運算子）。

乘以7

給出一種不使用乘法(*)運算子將整數乘以7的快速方法？

💡 點選檢視解答
// (x << 3) - x
// 其中 << 是位左移運算子
// x << 3 等價於 x * 8
// 所以 (x << 3) - x = x * 8 - x = x * 7
int multiplyBy7(int x) {
    return (x << 3) - x;
}

機率模擬

給你一枚公平硬幣。你能設計一個使用公平硬幣的簡單遊戲，使得你的獲勝機率為 \(p\)，\(0 < p < 1\)？

💡 點選檢視解答

關鍵認識到 \(p \in (0,1)\) 可以表示為二進位制數，每一位都可以用公平硬幣模擬。

首先，將機率 \(p\) 表示為二進位制數：

\[p = 0.p_1p_2\cdots p_n = p_1 \cdot 2^{-1} + p_2 \cdot 2^{-2} + \cdots + p_n \cdot 2^{-n}, \quad p_i \in \{0, 1\}\]

然後開始拋硬幣，將正面計為1，反面計為0。設 \(s_i\) 為第 \(i\) 次拋擲的結果：

演算法：
1. 將 p 表示為二進位制: p = 0.p₁p₂...pₙ
2. 從 i = 1 開始拋硬幣，得到 sᵢ
3. 比較 pᵢ 與 sᵢ：
   - 如果 sᵢ < pᵢ（即 sᵢ=0, pᵢ=1）→ 贏，停止
   - 如果 sᵢ > pᵢ（即 sᵢ=1, pᵢ=0）→ 輸，停止
   - 如果 sᵢ = pᵢ → 繼續拋第 i+1 次
4. 若序列有限且到最後 sₙ = pₙ → 輸

某些 \(p\) 值（如1/3）表示為二進位制時是無限序列。隨著 \(i\) 增加，達到 \(s_i \neq p_i\) 的機率趨向1。

毒酒

你有1000瓶酒準備在生日派對上使用。派對前20小時，酒莊說有一瓶被下了毒。你有10只實驗鼠可以用來測試。毒性很強，任何量的毒酒都會在恰好18小時後殺死老鼠。有沒有一種確定的方法在派對前用10只老鼠找到被下毒的瓶子？

💡 點選檢視解答

由於症狀要到18小時後才顯現，不能依次測試。但二分查詢的思想仍然適用。

關鍵洞察：1到1000之間的所有整數都可以用10位二進位制格式表示（\(2^{10} = 1024 > 1000\)）。

方法：
1. 將每瓶酒用10位二進位制編號
   例如：第1000瓶 = 1111101000

2. 讓老鼠k（k=1,...,10）從第k位為1的所有酒中各喝一口
   - 老鼠1：喝所有第1位(最低位)為1的酒
   - 老鼠2：喝所有第2位為1的酒
   - ...
   - 老鼠10：喝所有第10位(最高位)為1的酒

3. 18小時後觀察結果：
   - 將老鼠從最高位到最低位排列
   - 活鼠 → 0，死鼠 → 1
   - 得到的二進位制數即為有毒瓶子的編號

示例：如果第6、7、9號鼠死了而其他都活著，排列得到 0101100000，有毒瓶子編號為 \(2^8 + 2^6 + 2^5 = 352\)。

7.3 數值方法

許多金融工具的價格沒有封閉形式的解析解。這些金融工具的估值依賴於各種數值方法。本節討論蒙特卡洛模擬（Monte Carlo Simulation）和有限差分方法（Finite Difference Methods）的應用。

蒙特卡洛模擬

蒙特卡洛模擬是一種使用具有適當機率的隨機數作為輸入來迭代評估確定性模型的方法。對於衍生品定價，它模擬大量標的資產價格路徑，計算每條路徑衍生品的折現收益，並取平均得到衍生品價格。其有效性依賴於大數定律。

A. 解釋如何使用蒙特卡洛模擬對歐式看漲期權定價？

💡 點選檢視解答

假設股票價格遵循幾何布朗運動，將時間 \([t, T]\) 分成 \(N\) 個等間隔時間步，\(\Delta t = \frac{T-t}{N}\)。

在風險中性機率下模擬股票價格路徑：

\[S_i = S_{i-1} \cdot e^{(r-\sigma^2/2)\Delta t + \sigma\sqrt{\Delta t}\,\varepsilon_i}\]

其中 \(\varepsilon_i\) 是獨立同分布標準正態隨機變數。

假設模擬 \(M\) 條路徑，每條路徑產生到期股價 \(S_{T,k}\)，歐式看漲期權的估計價格為：

\[C = e^{-r(T-t)}\frac{\sum_{k=1}^{M}\max(S_{T,k} - K, 0)}{M}\]

B. 如果計算機只能生成[0,1]均勻分佈隨機變數，如何生成服從 \(N(\mu, \sigma^2)\) 的隨機變數？

💡 點選檢視解答

分兩步解決：

  1. 從均勻隨機數生成 \(x \sim N(0,1)\) 的隨機變數
  2. 將 \(x\) 縮放為 \(\mu + \sigma x\) 生成 \(N(\mu, \sigma^2)\) 隨機變數

逆變換方法

對於CDF為 \(F\) 的連續隨機變數 \(X\)，可通過 \(X = F^{-1}(U)\) 生成，其中 \(U \sim \text{Uniform}(0,1)\)。但標準正態的反函式無解析解。

接受-拒絕方法

使用指數分佈 \(g(x) = e^{-x}\) 作為輔助分佈（其逆CDF有解析解 \(x = -\log(1-u)\)）：

\[\frac{f(x)}{g(x)} = \sqrt{\frac{2}{\pi}}e^{x-x^2/2} \leq \sqrt{\frac{2}{\pi}}e^{1/2} \approx 1.32 = M\] 
接受-拒絕演算法：
1. 抽樣步驟：從 g(y) 生成隨機變數 y，從 U(0,1) 生成 v
2. 接受/拒絕步驟：
   如果 v ≤ f(y)/(M·g(y))，接受 x = y
   否則，重複步驟1
3. 最終：result = μ + σ·x

C. 你能解釋一些方差縮減技術嗎？

💡 點選檢視解答

蒙特卡洛估計量 \(\bar{Y} = \frac{1}{M}\sum_{i=1}^{M}Y_i\) 的方差為 \(Var(\bar{Y}) = \sigma/\sqrt{M}\)。以下技術可減少方差：

1. 對偶變數（Antithetic Variable）

對每組 \(\varepsilon_i\)，同時計算 \(Y(\varepsilon_1, \cdots, \varepsilon_N)\) 和 \(Y(-\varepsilon_1, \cdots, -\varepsilon_N)\)。當兩者負相關時方差減小。

2. 矩匹配（Moment Matching）

重新縮放樣本使樣本的矩（均值和方差）匹配所需的總體矩。

3. 控制變數（Control Variate）

如果有密切相關且有解析解的衍生品 \(Y\)，用相同隨機序列對 \(X\) 和 \(Y\) 定價，估計 \(X\) 為 \(\hat{X} + (Y - \hat{Y})\)。

4. 重要性抽樣（Importance Sampling）

\[E_{f(x)}[h(x)] = \int\frac{h(x)f(x)}{g(x)}g(x)dx = E_{g(x)}\left[\frac{h(x)f(x)}{g(x)}\right]\]

如果 \(\frac{h(x)f(x)}{g(x)}\) 比 \(h(x)\) 方差更小，則更高效。適用於深度虛值期權定價。

5. 低差異序列（Low-discrepancy Sequence）

使用確定性序列代替隨機樣本，可使收斂速率達到 \(1/M\)。

D. 如果一個期權沒有封閉形式定價公式，如何估計它的Delta和Gamma？

💡 點選檢視解答

對三個起始價格 \(S - \delta S\)、\(S\) 和 \(S + \delta S\) 執行蒙特卡洛模擬，得到對應期權價格 \(f(S - \delta S)\)、\(f(S)\) 和 \(f(S + \delta S)\)。

估計的Delta：

\[\Delta = \frac{f(S + \delta S) - f(S - \delta S)}{2\delta S}\]

估計的Gamma：

\[\Gamma = \frac{f(S + \delta S) - 2f(S) + f(S - \delta S)}{(\delta S)^2}\]

為減少方差，最好使用相同的隨機數序列來估計三個價格。

E. 如何使用蒙特卡洛模擬估計 \(\pi\)？

💡 點選檢視解答

在單位正方形中隨機選取點（\(x, y\) 為0到1間獨立均勻隨機變數），確定落在單位圓內的點的比例：

\[\hat{p} = \frac{\text{滿足 } x_i^2 + y_i^2 \leq 1 \text{ 的點數}}{\text{總點數}} = \frac{\pi/4}{1} \Rightarrow \hat{\pi} = 4\hat{p}\] 
估計π的演算法：
1. 設 count = 0, total = M
2. For k = 1 to M:
     生成 x ~ U(0,1), y ~ U(0,1)
     If x² + y² ≤ 1 then count = count + 1
3. π̂ = 4 × count / M

用1,000,000個點進行1,000次模擬，\(\pi\) 的平均估計為3.1416，標準差為0.0015。

有限差分方法

有限差分方法通過離散化時間和標的證券價格，數值求解微分方程來估計衍生品價格。將BSM方程轉化為熱擴散方程後，通過建立 \(x\) 和 \(\tau\) 的網格並使用邊界條件，遞迴計算各節點上的 \(u\) 值。

A. 你能簡要解釋有限差分方法嗎？

💡 點選檢視解答

將 \(\tau\) 的範圍 \([0, T]\) 分成 \(N\) 個離散區間（\(\Delta\tau = T/N\)），將 \(x\) 的範圍 \([x_0, x_J]\) 分成 \(J\) 個離散區間（\(\Delta x = (x_J - x_0)/J\)）。

顯式差分方法

使用時間 \(\tau_n\) 的前向差分和 \(x_j\) 處的二階中心差分：

\[\frac{u_j^{n+1} - u_j^n}{\Delta\tau} = \frac{u_{j+1}^n - 2u_j^n + u_{j-1}^n}{(\Delta x)^2}\]

整理得：

\[u_j^{n+1} = \alpha u_{j-1}^n + (1-2\alpha)u_j^n + \alpha u_{j+1}^n, \quad \alpha = \frac{\Delta\tau}{(\Delta x)^2}\]

隱式差分方法

使用時間 \(\tau_{n+1}\) 的後向差分：

\[\frac{u_j^{n+1} - u_j^n}{\Delta\tau} = \frac{u_{j+1}^{n+1} - 2u_j^{n+1} + u_{j-1}^{n+1}}{(\Delta x)^2}\]

Crank-Nicolson方法

使用時間 \((\tau_n + \tau_{n+1})/2\) 的中心差分：

\[\frac{u_j^{n+1} - u_j^n}{\Delta\tau} = \frac{1}{2}\left(\frac{u_{j+1}^n - 2u_j^n + u_{j-1}^n}{(\Delta x)^2} + \frac{u_{j+1}^{n+1} - 2u_j^{n+1} + u_{j-1}^{n+1}}{(\Delta x)^2}\right)\]

B. 使用顯式有限差分方法時，時間維度步數過多還是空間維度步數過多更糟糕？

💡 點選檢視解答

顯式方法的穩定性條件為：

\[1-2\alpha > 0 \Rightarrow \frac{\Delta\tau}{(\Delta x)^2} < \frac{1}{2}\]

空間維度步數過多更糟糕。

  • 小的 \(\Delta\tau\)（多時間步）是可取的，有利於穩定性
  • 小的 \(\Delta x\)（多空間步）可能使 \(\Delta\tau/(\Delta x)^2 > 1/2\)，導致不穩定

相比之下，隱式差分方法始終穩定且收斂，不受此限制。
