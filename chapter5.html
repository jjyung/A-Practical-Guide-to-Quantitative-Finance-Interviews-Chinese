第五章 隨機過程與隨機微積分

在本章中，我們將涵蓋幾個主題——馬爾可夫鏈（Markov Chain）、隨機遊走（Random Walk）和鞅（Martingale）、動態規劃（Dynamic Programming）——這些內容通常不包含在機率論入門課程中。與基礎機率理論不同，這些工具可能不被視為量化研究員/分析師的標準要求。但是，對這些主題的良好理解可以簡化你在許多面試問題中的回答，並在面試過程中給你帶來優勢。

5.1 馬爾可夫鏈（Markov Chain）

馬爾可夫鏈是一個隨機變數序列 \(X_0, X_1, \cdots, X_n, \cdots\)，具有馬爾可夫性質，即給定當前狀態，未來狀態與過去狀態獨立：

\[P\{X_{n+1} = j \mid X_n = i, X_{n-1} = i_{n-1}, \cdots, X_0 = i_0\} = p_{ij} = P\{X_{n+1} = j \mid X_n = i\}\]

對所有 \(n\)，\(i_0, \cdots, i_{n-1}\)，\(i\) 和 \(j\) 成立，其中 \(i, j \in \{1, 2, \cdots, M\}\) 表示 \(X\) 的狀態空間 \(S = \{s_1, s_2, ..., s_M\}\)。

換句話說，一旦當前狀態已知，過去的歷史對未來沒有影響。對於齊次馬爾可夫鏈，從狀態 \(i\) 到狀態 \(j\) 的轉移機率不依賴於 \(n\)。一個具有 \(M\) 個狀態的馬爾可夫鏈可以完全由一個 \(M \times M\) 的轉移矩陣 \(P\) 和初始機率 \(P(X_0)\) 來描述。

轉移矩陣：

\[P = \{p_{ij}\} = \begin{bmatrix} p_{11} & p_{12} & \cdots & p_{1M} \\ p_{21} & p_{22} & \cdots & p_{2M} \\ \vdots & \vdots & & \vdots \\ p_{M1} & p_{M2} & \cdots & p_{MM} \end{bmatrix}\]

吸收機率方程：到達特定吸收狀態 \(s\) 的機率 \(a_1, \cdots, a_M\)，滿足：對所有吸收狀態 \(s\)，\(a_s = 1\)；對所有非吸收狀態 \(i \neq s\)，\(a_i = 0\)；對所有瞬態狀態 \(i\)，\(a_i = \sum_{j=1}^{M} a_j p_{ij}\)。

期望吸收時間方程：對所有吸收狀態 \(i\)，\(\mu_i = 0\)；對所有瞬態狀態 \(i\)：

\[\mu_i = 1 + \sum_{j=1}^{m} p_{ij} \mu_j\]

賭徒破產問題（Gambler's Ruin Problem）

玩家 \(M\) 有1美元，玩家 \(N\) 有2美元。每局遊戲輸家給贏家1美元。作為較強的玩家，\(M\) 贏得2/3的遊戲。他們一直玩到某人破產。\(M\) 獲勝的機率是多少？

💡 點選檢視解答

狀態空間為 \(\{m\} = \{0, 1, 2, 3\}\)（\(m\) 為玩家 \(M\) 的美元數）。初始狀態 \(X_0 = 1\)。狀態0和3為吸收狀態。

轉移機率：\(p_{1,0} = 1/3\)，\(p_{1,2} = 2/3\)，\(p_{2,1} = 1/3\)，\(p_{2,3} = 2/3\)。

應用吸收機率方程：

\[\begin{cases} a_1 = 1/3 \times 0 + 2/3 \times a_2 \\ a_2 = 1/3 \times a_1 + 2/3 \times 1 \end{cases} \Rightarrow \begin{cases} a_1 = 4/7 \\ a_2 = 6/7 \end{cases}\]

所以，從1美元開始，玩家 \(M\) 獲勝的機率為 4/7。

骰子問題（Dice Question）

兩個玩家對兩個標準六面骰子的點數之和下注。玩家 \(A\) 賭總和12會先出現。玩家 \(B\) 賭連續兩個7會先出現。\(A\) 獲勝的機率是多少？

💡 點選檢視解答

狀態空間：\(S\)（起始）、7（一個7出現）、7-7（\(B\)贏，吸收）、12（\(A\)贏，吸收）。

\(P(F=12) = 1/36\)，\(P(F=7) = 6/36\)，\(P(F \notin \{7,12\}) = 29/36\)。

吸收機率方程：

\[a_S = 1/36 \times 1 + 6/36 \times a_7 + 29/36 \times a_S\] \[a_7 = 1/36 \times 1 + 6/36 \times 0 + 29/36 \times a_S\] \[\Rightarrow a_S = 7/13\]

所以 \(A\) 獲勝的機率為 7/13。

硬幣三連組（Coin Triplets）

A部分. 得到 HHH 連續出現的期望拋擲次數？得到 THH 的期望拋擲次數？

💡 點選檢視解答

對於 HHH，狀態空間：\(S\)、\(H\)、\(HH\)、\(HHH\)（吸收）。

\[\begin{cases} \mu_S = 1 + \frac{1}{2}\mu_S + \frac{1}{2}\mu_H \\ \mu_H = 1 + \frac{1}{2}\mu_S + \frac{1}{2}\mu_{HH} \\ \mu_{HH} = 1 + \frac{1}{2}\mu_S \end{cases} \Rightarrow \mu_S = 14\]

對於 THH，狀態空間：\(S\)、\(T\)、\(TH\)、\(THH\)（吸收）。

\[\begin{cases} \mu_S = 1 + \frac{1}{2}\mu_S + \frac{1}{2}\mu_T \\ \mu_T = 1 + \frac{1}{2}\mu_T + \frac{1}{2}\mu_{TH} \\ \mu_{TH} = 1 + \frac{1}{2}\mu_T \end{cases} \Rightarrow \mu_S = 8\]

得到 HHH 的期望次數為 14，得到 THH 的期望次數為 8。

B部分. 在 THH 之前得到 HHH 子序列的機率是多少？

💡 點選檢視解答

狀態空間：\(S\)、\(T\)、\(H\)、\(TH\)、\(HH\)、\(THH\)（吸收）、\(HHH\)（吸收）。

\[a_{HHH} = 1, \quad a_{THH} = 0\] \[a_S = \frac{1}{2}a_T + \frac{1}{2}a_H, \quad a_T = \frac{1}{2}a_T + \frac{1}{2}a_{TH}\] \[a_H = \frac{1}{2}a_T + \frac{1}{2}a_{HH}, \quad a_{TH} = \frac{1}{2}a_T + \frac{1}{2}a_{THH}\] \[a_{HH} = \frac{1}{2}a_T + \frac{1}{2}a_{HHH}\]

解得 \(a_T = 0\)，\(a_S = 1/8\)。

直覺解釋：一旦出現反面，我們總是會在 HHH 之前得到 THH。唯一在 THH 之前得到 HHH 的方式是開頭就丟擲三個連續正面（機率1/8）。

C部分. 三連組遊戲中兩個理性玩家各選三連組，後手獲勝機率是多少？

💡 點選檢視解答

無論玩家1選擇什麼序列，玩家2總能選擇一個具有超過1/2獲勝機率的序列。關鍵是選擇以玩家1序列的最後兩枚硬幣作為自己序列的前兩枚硬幣。

為最大化獲勝機率，玩家1應從 HTH、HTT、THH 和 THT 中選擇，但即使如此，玩家2也有 2/3 的獲勝機率。所以後手更有利。

彩色球（Color Balls）

一個盒子中有 \(n\) 個球，共 \(n\) 種不同顏色。每次隨機選擇一對球，將第一個球重新塗成第二個球的顏色。期望需要多少步使所有球變成同一顏色？

💡 點選檢視解答

利用對稱性，假設最終所有球變為顏色1（機率 \(1/n\)）。用顏色1球的數量 \(i\) 作為狀態。

條件轉移機率：

\[P(x_{k+1} = i-1 \mid x_k = i, F_1) = \frac{(n-i)(i-1)}{n(n-1)}\] \[P(x_{k+1} = i \mid x_k = i, F_1) = \frac{(n-i) \times 2i}{n(n-1)}\] \[P(x_{k+1} = i+1 \mid x_k = i, F_1) = \frac{(n-i)(i+1)}{n(n-1)}\]

利用遞迴方程和邊界條件 \(Z_n = 0\)，最終得到 \(E[N_n] = Z_1 = (n-1)^2\)。

5.2 鞅與隨機遊走（Martingale and Random Walk）

隨機遊走：如果 \(\{X_i; i \geq 1\}\) 是獨立同分布隨機變數，且 \(S_n = X_1 + \cdots + X_n\)，則 \(\{S_n\}\) 稱為隨機遊走。

鞅：鞅 \(\{Z_n\}\) 是滿足 \(E[Z_{n+1} \mid Z_n, \cdots, Z_1] = Z_n\) 的隨機過程。對稱隨機遊走是一個鞅，\(S_n^2 - n\) 也是一個鞅。

瓦爾德等式：令 \(N\) 為IID隨機變數的停止規則，則 \(E[S_N] = E[X]E[N]\)。

在停止時間停止的鞅仍然是鞅。

醉漢問題（Drunk Man）

一個醉漢在100米長橋的第17米處。每步50%機率前進或後退1米。到達終點（100米）而不到達起點（0米）的機率？到達起點或終點的期望步數？

💡 點選檢視解答

令當前位置為0，則在83或-17處停止。\(S_n\) 和 \(S_n^2 - n\) 都是鞅。

令 \(p_\alpha\) 為停在83處的機率，\(N\) 為停止時間：

\[E[S_N] = p_\alpha \times 83 - (1-p_\alpha) \times 17 = 0\] \[E[S_N^2 - N] = p_\alpha \times 83^2 + (1-p_\alpha) \times 17^2 - E[N] = 0\] \[\Rightarrow p_\alpha = 0.17, \quad E[N] = 1411\]

一般結論：從0開始的對稱隨機遊走，在 \(\alpha\) 或 \(-\beta\) 處停止，停在 \(\alpha\) 的機率為 \(p_\alpha = \beta/(\alpha + \beta)\)，期望停止時間為 \(E[N] = \alpha\beta\)。

骰子游戲（Dice Game）

擲骰子得面值對應美元數。擲出4、5或6可再擲，擲出1、2或3遊戲停止。期望收益？

💡 點選檢視解答

應用瓦爾德等式。停止時間 \(N\) 服從幾何分佈（\(p = 1/2\)），\(E[N] = 2\)。每次期望面值 \(E[X] = 7/2\)。

\[E[S_N] = E[X]E[N] = \frac{7}{2} \times 2 = 7\]

售票佇列（Ticket Line）

\(2n\) 人排隊買5美元票。\(n\) 人有5美元，\(n\) 人有10美元。售票員無零錢。所有人順利買票的機率？

💡 點選檢視解答

賦值 +1（5美元）和 -1（10美元）。從 \((0,0)\) 到 \((2n,0)\) 共 \(\binom{2n}{n}\) 條路徑。使用反射原理，滿足 \(b \geq 0\) 的路徑數為：

\[\binom{2n}{n} - \binom{2n}{n-1} = \frac{1}{n+1}\binom{2n}{n}\]

機率為 \(\dfrac{1}{n+1}\)。

硬幣序列（Coin Sequence）

得到連續 \(n\) 次正面的期望拋擲次數是多少？

💡 點選檢視解答

結論：\(E[f(n)] = 2^{n+1} - 2\)。

歸納法證明：

\[E[f(n+1)] = E[f(n)] + \frac{1}{2} \times 1 + \frac{1}{2} \times (1 + E[f(n+1)])\] \[\Rightarrow E[f(n+1)] = 2E[f(n)] + 2 = 2(2^{n+1}-2) + 2 = 2^{n+2} - 2\]

鞅方法：利用停止鞅過程，在停止時總收益固定為 \(2^n + 2^{n-1} + \cdots + 2 = 2^{n+1} - 2\)，因此期望時間也是 \(2^{n+1} - 2\)。

例如序列 HHTTHH：\(E[i] = 2^6 + 2^2 + 2^1 = 70\)。

5.3 動態規劃（Dynamic Programming）

動態規劃是一類用於解決序列性或多階段決策問題的一般方法。基本邏輯：從最終階段（擁有最多資訊的階段）的最優策略開始，逆向推導到初始階段。

DP演算法：從 \(J_N(x_N) = g_N(x_N)\) 開始，逆向計算：

\[J_k(x_k) = \min_{u_k \in U_k(x_k)} E_{w_k}\{g_k(x_k, u_k, w_k) + J_{k+1}(f(x_k, u_k, w_k))\}\]

骰子游戲（Dice Game）

擲6面骰子最多3次。每次可以選擇拿面值美元或繼續擲。第三次必須接受結果。遊戲價值和最優策略？

💡 點選檢視解答

逆向推導：

  • 第三次擲骰（最終階段）：期望收益 = 3.5美元
  • 第二次擲骰後：面值 > 3.5 時保留，否則繼續。期望收益 = \(3/6 \times 3.5 + 1/6 \times (4+5+6) = 4.25\) 美元
  • 第一次擲骰後：面值 > 4.25 時保留，否則繼續。期望收益 = \(4/6 \times 4.25 + 1/6 \times (5+6) = 14/3\) 美元

遊戲價值為 14/3 ≈ 4.67 美元。策略：第一次得5或6時停止，第二次得4、5或6時停止。

世界大賽（World Series）

七場四勝制。你有100美元要賭紅襪隊，但只能對每場下注。如何下注使得紅襪贏系列賽恰好贏100，輸則恰好輸100？

💡 點選檢視解答

令 \(f(i,j)\) 為紅襪贏 \(i\) 場對手贏 \(j\) 場時的淨收益。邊界條件：\(f(4,j) = 100\)，\(f(i,4) = -100\)。

遞推關係：

\[f(i,j) = \frac{f(i+1,j) + f(i,j+1)}{2}\]

每場下注金額：

\[y = \frac{f(i+1,j) - f(i,j+1)}{2}\]

例如 \(f(3,3) = 0\)，下注50；\(f(0,0) = 0\)，下注 \(100/2^6 \approx 1.5625\) 美元。這本質上是一個二叉樹中的動態對沖問題。

動態骰子游戲（Dynamic Dice Game）

擲骰子可以任意多次，除非出現6（則輸掉所有累積的錢）。擲出1-5時贏對應美元數。每次可選擇保留或繼續。願意花多少錢玩？

💡 點選檢視解答

累積 \(n\) 美元時再擲一次的期望收益：\(\frac{5}{6}n + 2.5\)。當 \(\frac{5}{6}n + 2.5 > n\) 即 \(n < 15\) 時應繼續。

當 \(n \geq 15\) 時停止。最大收益19美元。遞迴計算 \(E[f(n)]\)：

\[E[f(n) \mid n \leq 14] = \frac{1}{6}\sum_{i=1}^{5} E[f(n+i)]\]

最終 \(E[f(0)] = 6.15\) 美元。願意支付最多 6.15美元。

動態紙牌遊戲（Dynamic Card Game）

52張牌（26紅26黑）。逐一翻牌，紅 +1美元，黑 -1美元，可隨時停止。最優策略和遊戲價值？

💡 點選檢視解答

令 \((b,r)\) 為剩餘黑牌和紅牌數。收益 = 已翻紅牌 - 已翻黑牌 = \(b - r\)。

系統方程（類似美式期權）：

\[E[f(b,r)] = \max\left(b-r, \frac{b}{b+r}E[f(b-1,r)] + \frac{r}{b+r}E[f(b,r-1)]\right)\]

邊界條件：\(f(0,r) = 0\)，\(f(b,0) = b\)。

遞迴計算得 \(E[f(26,26)] = \mathbf{2.62}\) 美元。

5.4 布朗運動與隨機微積分（Brownian Motion and Stochastic Calculus）

布朗運動（Brownian Motion）

A. 定義並列舉布朗運動的性質。

💡 點選檢視解答

連續隨機過程 \(W(t)\)，\(t \geq 0\)，若滿足以下條件則為布朗運動：

  • \(W(0) = 0\)
  • 增量獨立：\(W(t_1)-W(0), W(t_2)-W(t_1), \cdots\) 獨立
  • 增量正態：\(W(t_{i+1}) - W(t_i) \sim N(0, t_{i+1} - t_i)\)

重要性質：連續；\(E[W(t)] = 0\)；\(E[W(t)^2] = t\)；鞅性質；馬爾可夫性質。

重要鞅：

  • \(Y(t) = W(t)^2 - t\) 是鞅
  • \(Z(t) = \exp\{\lambda W(t) - \frac{1}{2}\lambda^2 t\}\)（指數鞅）是鞅

B. 布朗運動與其平方的相關係數是多少？

💡 點選檢視解答

\(B_t \sim N(0,t)\)，由對稱性 \(E[B_t^3] = 0\)。\(Cov(B_t, B_t^2) = E[B_t^3] - E[B_t]E[B_t^2] = 0\)。

相關係數為 0。

C. \(P(B_1 > 0 \text{ 且 } B_2 < 0)\) = ?

💡 點選檢視解答

\(B_1 \sim N(0,1)\)，\(B_2 - B_1 \sim N(0,1)\) 且獨立於 \(B_1\)。

\[P(B_1 > 0, B_2 < 0) = P(B_1 > 0)P(B_2-B_1 < 0)P(|B_2-B_1| > |B_1|) = \frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}\]

停止時間/首次通過時間

A. 布朗運動到達 -1 或 1 的平均停止時間？

💡 點選檢視解答

\(B_t^2 - t\) 是鞅（用伊藤引理可證）。令 \(T = \min\{t; B_t = 1 \text{ 或 } -1\}\)。

在停止時間停止的鞅仍是鞅：\(E[B_T^2 - T] = 0\)。由於 \(B_T^2 = 1\)，所以 \(E[T] = 1\)。

B. 首次通過水平 \(x\) 的時間 \(\tau_x\) 的密度函式和期望？

💡 點選檢視解答

利用反射原理：\(P(\tau_x \leq t) = 2P(W(t) \geq x) = 2 - 2N(x/\sqrt{t})\)

對 \(t\) 求導：

\[f_{\tau_x}(t) = \frac{x e^{-x^2/2t}}{t\sqrt{2\pi t}}, \quad x > 0\]

期望：\(E[\tau_x] = \infty\)（雖然 \(P(\tau_x < \infty) = 1\)）。

C. \(dX = dW(t)\) 從0出發，達到3而不是-5的機率？有漂移 \(m\) 時呢？

💡 點選檢視解答

無漂移：\(3P_3 + (-5)(1-P_3) = 0 \Rightarrow P_3 = 5/8\)。

有漂移 \(m\)：用指數鞅 \(E[\exp(-2mX)] = 1\)，設 \(\lambda = -2m\)：

\[P_3 e^{-6m} + (1-P_3)e^{10m} = 1 \Rightarrow P_3 = \frac{e^{10m} - 1}{e^{10m} - e^{-6m}}\]

D. \(dX = dt + dW(t)\)，\(X\) 從0出發，曾到達-1的機率？

💡 點選檢視解答

用正邊界 \(+\infty\)：\(P_{-1}e^{2} + (1-P_{-1})e^{-\infty} = 1\)。

由於 \(e^{-\infty} = 0\)：\(P_{-1} = e^{-2} \approx 0.135\)。

伊藤引理（Ito's Lemma）

設 \(X(t)\) 滿足 \(dX = \beta dt + \gamma dW(t)\)，\(f(X,t)\) 為二階可微函式，則：

\[df = \left(\frac{\partial f}{\partial t} + \beta\frac{\partial f}{\partial x} + \frac{1}{2}\gamma^2\frac{\partial^2 f}{\partial x^2}\right)dt + \gamma\frac{\partial f}{\partial x}dW(t)\]

A. \(Z_t = \sqrt{t}B_t\) 是鞅嗎？

💡 點選檢視解答

\(Z_t \sim N(0, t^2)\)，均值為0，方差為 \(t^2\)。

應用伊藤引理：\(dZ_t = \frac{1}{2}t^{-1/2}B_t\,dt + \sqrt{t}\,dB_t\)。漂移項 \(\frac{1}{2}t^{-1/2}B_t\) 不為零，所以 不是鞅。

B. \(W(t)^3\) 是鞅嗎？

💡 點選檢視解答

應用伊藤引理：\(d(W^3) = 3W(t)\,dt + 3W(t)^2\,dW(t)\)。漂移項 \(3W(t)\) 不為零，所以 不是鞅。
